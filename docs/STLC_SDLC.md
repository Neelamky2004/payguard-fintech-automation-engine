# STLC & SDLC Integration Strategy

## SDLC Mapping
* **Requirement Analysis**: Analyzed fintech user stories, multi-currency ledger rules, and security compliance requirements.
* **Design**: Designed Page Object Model (POM) architecture, BDD feature files, and robust test harness layers.
* **Development**: Implemented Java 17, Selenium 4.18, TestNG, and Maven automation suites.
* **Testing**: Executed automated Smoke, Sanity, and Regression testing matrices.
* **Deployment**: Configured GitHub Actions CI/CD pipelines (windows-latest).
* **Maintenance**: Continuous updating of assertions, test dependencies, and workflow scripts.

## STLC Mapping
* **Requirement Analysis**: Reviewing automation feasibility for financial clearance workflows.
* **Test Planning**: Structuring test groups, Maven surefire configurations, and reporting structures.
* **Test Case Design**: Writing granular Cucumber features and TestNG test classes.
* **Test Environment Setup**: Configuring Java 17, Maven cache, and driver runtimes.
* **Test Execution**: Running suite executions locally (mvn test) and via GitHub Actions.
* **Defect Reporting**: Analyzing surefire reports and console execution failure logs.
* **Regression**: Validating stability across multi-currency pipelines.
* **Test Closure**: Finalizing test execution summaries and metrics documentation.
